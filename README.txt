WEBSITE PORTOFOLIO — RANI NOVITA DURI
Tema: Navy Blue + Cream, font Times New Roman

Cara membuka:
1. Ekstrak ZIP, buka folder portfolio_rani.
2. Klik dua kali index.html.

File:
- index.html     : struktur dan konten
- style.css      : desain navy-cream, tombol 3D, responsif
- script.js      : menu mobile dan tahun footer
- foto-rani.jpg  : foto profil (sudah di-crop potret 4:5)

Catatan:
- Ilustrasi proyek adalah ilustrasi tampilan, bukan screenshot asli.
- Periksa kembali bagian sertifikasi agar sesuai dokumen yang dimiliki.

MENGGANTI LINK (penting)
Buka script.js, bagian LINKS di paling atas. Isi link Google Drive untuk
proyek1-4, sertifikat1-5, cv, serta instagram dan github.
Link yang kosong tidak aktif (Instagram, GitHub, CV disembunyikan otomatis).

GAMBAR & GALERI (script.js, bagian GALLERIES)
- Klik kartu proyek atau sertifikat membuka penampil gambar (bisa geser kiri/kanan, Esc untuk menutup).
- Gambar ada di folder assets/proyek dan assets/sertifikat.
- Link demo/GitHub proyek diisi di LINKS: proyek1_demo, proyek1_github, dst.
